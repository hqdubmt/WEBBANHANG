# PROJECT_AI_SOCIAL_COMMERCE_V1

## 1. Mục tiêu

Xây dựng hệ thống AI Agent bán hàng tự động đa nền tảng:

* Facebook
* TikTok
* Zalo
* Telegram
* Website

Hệ thống có khả năng:

* Đăng bài tự động
* Tìm sản phẩm hot
* Gắn link affiliate
* Trả lời khách hàng bằng AI
* Thu thập lead
* Chăm sóc khách hàng
* Tạo đơn hàng
* Theo dõi doanh thu

# 4. Các Agent AI

## Agent 01 - Trend Hunter

Nhiệm vụ:

* Quét sản phẩm hot
* Quét deal hot
* Theo dõi xu hướng

Nguồn:

* Shopee
* Lazada
* TikTok Shop
* Facebook

Output:

```json
{
  "product": "",
  "category": "",
  "score": 0,
  "reason": ""
}
```

---

## Agent 02 - Affiliate Hunter

Nhiệm vụ:

* Tìm sản phẩm có hoa hồng cao
* So sánh giá
* Chọn link affiliate tốt nhất

Output:

```json
{
  "product": "",
  "platform": "",
  "affiliate_link": "",
  "commission": 0
}
```

---

## Agent 03 - Content Creator

Tự động tạo:

* Bài Facebook
* Bài Telegram
* Bài Website
* Kịch bản video TikTok

Output:

```json
{
  "title": "",
  "content": "",
  "hashtags": []
}
```

---

## Agent 04 - Social Publisher

Đăng bài tự động:

* Facebook
* Telegram
* Website
* TikTok

---

## Agent 05 - Lead Hunter

Tìm khách hàng tiềm năng.

Nguồn:

* Facebook Group
* Telegram Group

Phát hiện:

* Người cần mua
* Người cần tư vấn
* Người đang hỏi giá

---

## Agent 06 - AI Sales

Tự động:

* Trả lời inbox
* Tư vấn sản phẩm
* So sánh sản phẩm
* Chốt đơn

---

## Agent 07 - CRM Agent

Theo dõi:

* Khách mới

* Khách VIP

Tự động chăm sóc.
