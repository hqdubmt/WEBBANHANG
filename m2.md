# DATA SOURCES

## TrendAgent
- Queue: `trend-agent` — subscribe kết quả trend scan
- Output: trending keywords, hot products, emerging niches

## AffiliateAgent
- Entity: `AffiliateClick` — đếm click, conversion, revenue
- Output: top affiliates, affiliate ROI by product

## CRM Agent
- Entity: `Customer`, `Lead` — audience segments, lifecycle stages
- Output: segment sizes, conversion by segment

## Revenue Autopilot
- Entity: `RevenueSnapshot` — KPIs tổng hợp
- Output: revenue health, bottlenecks, growth rate

## Campaign Engine
- Entity: `Campaign` — campaign performance data
- Output: ROI, ROAS, top campaigns

## Content/Video/SEO Engines
- Entity: `Content`, `AgentLog` — output metrics
- Output: content volume, engagement, organic traffic

# MARKET INTELLIGENCE

`MarketingIntelligenceService.collectSignals()`:

Cron: `@Cron('0 */6 * * *')` — mỗi 6 giờ.

```typescript
interface MarketSignals {
  collectedAt: Date;
  trends: {
    keywords: string[];
    hotProducts: string[];
    emergingNiches: string[];
  };
  competitors: {
    priceChanges: any[];
    newProducts: any[];
  };
  customerDemand: {
    topSearchTerms: string[];
    demandSpike: { product: string; uplift: number }[];
  };
  opportunities: MarketOpportunity[];
}

interface MarketOpportunity {
  type: 'trending_product' | 'emerging_niche' | 'seasonal' | 'affiliate' | 'cross_sell' | 'upsell';
  description: string;
  estimatedRevenue: number;
  effort: 'low' | 'medium' | 'high';
  urgency: 'immediate' | 'this_week' | 'this_month';
  recommendedAction: string;
  triggerModule: string;
}
```

Kết quả emit vào event `marketing.opportunity.detected`.

# OPPORTUNITY ENGINE

`MarketingIntelligenceService.detectOpportunities()`:

| Opportunity Type | Detection Logic | Action |
|-----------------|-----------------|--------|
| Trending Product | TrendAgent score > 80 | Create ProductLaunch campaign |
| Emerging Niche | 3+ new keywords trong 48h | Create ContentCampaign |
| Seasonal | Date-based rules + past performance | Create SeasonalCampaign |
| Affiliate Opportunity | Affiliate conversion > 5% | Scale affiliate program |
| Cross-sell | Customer segment với AOV headroom | CRM campaign |
| Upsell | Customer tier = 'regular' + purchase history | Sales Agent trigger |

# AUDIENCE ORCHESTRATION

`MarketingResourceService.buildAudiencePlans()`:

Query từ `Customer` và `Lead`:

```typescript
const audiences = {
  coldAudience: await leadRepo.count({ where: { status: 'new' } }),
  warmAudience: await leadRepo.count({ where: { status: 'contacted' } }),
  customers: await customerRepo.count({ where: { tier: 'regular' } }),
  vipCustomers: await customerRepo.count({ where: { tier: 'vip' } }),
  inactiveCustomers: /* lastOrderDate < 60 days */ ,
  affiliates: await affiliateRepo.count({ where: { status: 'active' } }),
};
```

Map audience → channel:
- Cold Audience → SEO + Content (organic)
- Warm Audience → Email + Telegram (nurture)
- Customers → Upsell campaigns
- VIP → Personal outreach via CRM
- Inactive → Reactivation campaigns

# MARKETING HEALTH SCORE

`MarketingHealthService.calculateScore()`:

```typescript
interface MarketingHealthScore {
  trafficQuality: number;      // 0-20: traffic volume + conversion rate
  leadQuality: number;         // 0-20: lead score + qualification rate
  campaignPerformance: number; // 0-20: avg ROI across active campaigns
  customerAcquisition: number; // 0-15: CAC vs target
  revenueContribution: number; // 0-15: marketing-attributed revenue
  brandGrowth: number;         // 0-10: content output + SEO growth
  total: number;               // 0-100
  grade: 'A' | 'B' | 'C' | 'D' | 'F';
}
```

Ngưỡng:
- A: 80-100 — marketing đang hoạt động tốt
- B: 65-79 — tốt, có thể cải thiện
- C: 50-64 — cần chú ý
- D: 35-49 — cần hành động
- F: < 35 — marketing bị nghẽn nghiêm trọng

| Condition | Recommendation | Action |
|-----------|---------------|--------|

| Video engagement low | Tăng video chất lượng | VideoAgent: format review |
| Email CTR < 2% | Refresh email content | EmailAgent: new templates |
| Affiliate revenue drop | Review affiliate terms | AffiliateAgent: audit |
| Remarketing ROI > 3x | Scale remarketing | CampaignEngine: scale |
| Weak campaigns ROI < 1x | Giảm weak campaigns | CampaignEngine: pause |
