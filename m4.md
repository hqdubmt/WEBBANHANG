# AUTONOMOUS_COMPANY_V4.md

## MISSION

Xây dựng Autonomous Company Layer V4 — tầng tự vận hành doanh nghiệp hoàn chỉnh.

Mục tiêu:

Biến AI Social Commerce OS từ một tập hợp Agent và modules riêng lẻ thành một doanh nghiệp số có khả năng:

* Tự quan sát (Observe)
* Tự phân tích (Analyze)
* Tự ra quyết định (Decide)
* Tự thực thi (Execute)
* Tự đo lường (Measure)
* Tự học (Learn)
* Tự cải thiện (Improve)

một cách liên tục — không cần sự can thiệp của con người trong các quyết định vận hành hàng ngày.

# COMPANY OPERATING LOOP

`CompanyOperatingLoopService.runLoop()`:

Cron: `@Cron('0 */1 * * *')` — mỗi giờ (OODA loop).

```typescript
// OODA Loop — Observe, Orient, Decide, Act
async runOperatingLoop(): Promise<LoopResult> {
  // 1. OBSERVE
  const snapshot = await this.observe();

  // 2. ORIENT (Analyze)
  const analysis = await this.orient(snapshot);

  // 3. DECIDE
  const decisions = await this.decide(analysis);

  // 4. ACT (Execute)
  const execResults = await this.act(decisions);

  // 5. LEARN
  await this.learn(execResults);

  return { snapshot, analysis, decisions, execResults };
}
```

// Weekly self-improvement cycle
@Cron('0 9 * * 0')  // Sunday 09:00
async runSelfImprovementCycle(): Promise<ImprovementReport> {
  // 1. Analyze last week's decisions
  const decisions = await this.aiDecisionRepo.find({ 
    where: { createdAt: Between(lastWeek(), now()) }
  });
  
  // 2. Calculate success rate per decision type
  const analysis = this.analyzeSuccessRates(decisions);
  
  // 3. Adjust confidence thresholds
  await this.adjustThresholds(analysis);
  
  // 4. Update knowledge base
  await this.knowledgeBrainService.updatePatterns(analysis.newPatterns);
  
  // 5. Generate improvement report
  return this.generateReport(analysis);
}
