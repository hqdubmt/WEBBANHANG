## 2. Topic & Keyword Selection from Market Intelligence

### Nguồn Trend Data

| Nguồn | Agent | API |
|-------|-------|-----|
| TikTok trending hashtags | Trend Agent (Agent 01) | `/api/agents/trend/run` |
| Facebook trending topics | Trend Agent | Market Intelligence domain |
| Product demand signals | Demand Forecaster (Agent 19) | `/api/agents/demand-forecaster/run` |
| Competitor content gaps | Competitor Monitor (Agent 18) | `/api/agents/competitor-monitor/run` |
| Customer FAQs | Knowledge Brain | `/api/knowledge-brain/customers` |
| Search keywords | SEO Agent (Agent 09) | `/api/agents/seo/drafts` |

### Topic Selection Priority Matrix
```
Priority = TrendScore × BusinessValue × CompetitorGap

TrendScore:   0–100 (từ Trend Agent)
BusinessValue: 0–100 (conversion potential, margin)
CompetitorGap: 0–100 (100 = competitor chưa cover topic này)

Top 5 topics/week → scheduled cho Content Agent
```

## 3. Content Types

### FB Post (Facebook Text Post)
```
Format:    Text 500–1000 ký tự + 1–3 images + 5–10 hashtags
Tone:      Conversational, personal, local Vietnamese
Goal:      Engagement (likes/comments/shares)
Agent:     Content Agent → generates body + hashtags
Template:  HOOK + PROBLEM + SOLUTION + PROOF + CTA
```

### FB Carousel
```
Format:    5–10 cards, each card: image + 30-char title + link
Tone:      Educational, sequential storytelling
Goal:      Product discovery, traffic to website
Template:  Card1(Hook) + Card2-4(Features) + Card5(Offer) + Card6(CTA)
```

### TikTok Script
```
Format:    15–60 second script, hook in first 3 seconds
Structure: HOOK (3s) + PROBLEM (5s) + SOLUTION (15s) + PROOF (10s) + CTA (5s)
Tone:      Energetic, trendy, youth-oriented
Generated: Script text → passes to Video Agent for voice/visual
```

### SEO Article
```
Format:    800–2000 words, H1/H2/H3 structure
Entity:    SeoArticle {keyword, title, slug, content, metaDescription, clusterKeywords}
Goal:      Google ranking, organic traffic
Template:  Title + Intro + H2 sections + FAQ + Internal links + CTA
```

### Landing Page
```
Format:    Single product/campaign page
Sections:  Hero + Benefits + Proof + FAQ + Offer + CTA
Goal:      High conversion rate
Current:   Not yet automated — manual design in Next.js
```

### Email Newsletter
```
Format:    HTML email 300–800 words
Entity:    EmailCampaign table
Segments:  New customers / Regular / VIP / Win-back
Template:  Subject line + Preheader + Body + CTA + Unsubscribe
Agent:     Email Agent (Agent 13)
```
