
# CAMPAIGN_AUTOMATION_V2.md

## MISSION

Xây dựng Campaign Automation Engine — tầng tự động hóa chiến dịch marketing toàn diện.

Mục tiêu:

# CAMPAIGN TYPES

## Product Launch Campaign
- Trigger: TrendAgent phát hiện product demand spike
- Content: ContentFactory tạo 5 posts + VideoAgent tạo 1 video
- Channels: Facebook + Telegram + SEO
- Duration: 7-14 ngày
- KPI target: 50+ leads, AOV > baseline

## Promotion Campaign
- Trigger: RevenueAutopilot phát hiện conversion drop
- Content: ContentFactory tạo promotional posts với discount
- Channels: Facebook + Email + Telegram
- Duration: 3-7 ngày
- KPI target: 20% conversion lift

## Seasonal Campaign
- Trigger: Cron `@Cron('0 9 1 * *')` — đầu tháng check calendar
- Content: Pre-planned templates
- Channels: All channels
- Duration: 14-30 ngày
- KPI target: MoM revenue growth

## Affiliate Campaign
- Trigger: AffiliateAgent phát hiện opportunity
- Content: Affiliate-specific assets
- Channels: Affiliate network
- Duration: Ongoing
- KPI target: ROAS > 3x

## Retention Campaign
- Trigger: CrmAgent phát hiện churn risk
- Content: Personalized re-engagement
- Channels: Email + Telegram
- Duration: 7 ngày
- KPI target: 30% re-activation rate

## Reactivation Campaign
- Trigger: CrmAgent — customer inactive > 60 ngày
- Content: Win-back offer
- Channels: Email + SMS
- Duration: 5 ngày
- KPI target: 15% reactivation

# AUDIENCE ENGINE

`CampaignPlanningService.resolveAudience(segment)`:

```typescript
// Query Customer entity theo tier
const audiences = {
  new: customers WHERE tier = 'new' AND createdAt > 30 ngày,
  warm: leads WHERE status IN ('contacted', 'qualified'),
  customers: customers WHERE tier = 'regular',
  vip: customers WHERE tier = 'vip',
  inactive: customers WHERE lastOrderDate < 60 ngày
};
```

Đếm audience size trước khi plan — nếu < 10, không tạo campaign.

# KPI TRACKING

`CampaignKpiService.trackCampaignKpis(campaignId)`:

Cron: `@Cron('0 * * * *')` — mỗi giờ cho active campaigns.

```typescript
interface CampaignKpis {
  campaignId: string;
  period: 'hourly' | 'daily';
  impressions: number;        // từ metadata (social API webhook)
  clicks: number;             // từ AffiliateClick count
  ctr: number;                // clicks / impressions
  leads: number;              // Lead WHERE source = campaign.id
  orders: number;             // Order WHERE campaignCode = campaign.id
  revenue: number;            // SUM(Order.total) WHERE campaign
  cost: number;               // campaign.budget đã tiêu
  roi: number;                // (revenue - cost) / cost
  roas: number;               // revenue / cost
}
```

Lưu vào `Campaign.metadata.kpiHistory[]`.

# AI OPTIMIZATION ENGINE

`CampaignOptimizationService.evaluate(campaignId)`:

Cron: `@Cron('0 22 * * *')` — 22:00 hằng ngày.

Decision logic:

```typescript
if (roi < 0.5 && daysRunning > 3) {
  → PAUSE campaign
  → Emit alert 'campaign.underperforming'
  → Log AiDecision với recommendation
}

if (roi > 2.0 && daysRunning < endDate) {
  → SCALE: tăng budget 20%
  → Request thêm content từ ContentFactory
  → Log AiDecision với action
}

if (leads > targetLeads * 1.5) {
  → EXTEND campaign thêm 7 ngày
}

if (ctr < 0.5%) {
  → Request new creative từ ContentFactory
  → A/B test mới
}
```

# AUTOMATIC SCALING

`CampaignScalingService.autoScale()`:

Điều kiện scale UP:
- ROI > 2x sau 3 ngày
- Lead count > target × 1.2
- Conversion rate > 15%

Action khi scale:
- Tăng budget 20%
- Request 2x content output
- Mở rộng audience targeting

Điều kiện scale DOWN / PAUSE:
- ROI < 0.5x sau 3 ngày
- CTR < 0.3%
- Zero leads 48h
